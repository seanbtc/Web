# Binance U本位合约 资金费套利机器人
> 低风险无杠杆套利策略 | 全自动整点套利 | 精准成本核算 | 纯模块化解耦开发
> 适配 UTC+0 币安标准时区，无时间偏差，合规调用币安官方FAPI接口

## 📌 项目介绍
币安U本位合约专属资金费套利自动化程序，核心盈利逻辑为赚取交易所**资金费补贴**，不依赖行情涨跌，属于极低风险套利策略。
- ✅ 精准筛选资金费率在指定区间内的高收益交易对
- ✅ 全自动套利闭环：筛选标的 → 市价开仓 → 计费完成平仓
- ✅ 精准核算：双向手续费 + 市价单滑点成本，利润明细一目了然
- ✅ 纯面向对象+模块化拆分，代码易读/易维护/易扩展
- ✅ 完善的异常捕获机制，单个交易对异常不影响全局运行
- ✅ 盈利自动累计统计

## 📌 核心套利规则
1. 资金费率为 **正数(≥FUNDING_RATE_LOWER)** → 市价做空该交易对，赚取资金费收益
2. 资金费率为 **负数(≤-FUNDING_RATE_LOWER)** → 市价做多该交易对，赚取资金费收益

## 📌 策略运行完整流程

### 1. 程序启动与初始化
- 加载配置文件 `config.py` 中的核心参数
- 初始化币安API客户端，建立连接
- 初始化交易对信息，获取所有可交易的U本位合约交易对
- 读取资金费率周期配置，建立本地缓存

### 2. 资金费率周期管理
- 系统自动检测每个交易对的资金费率周期（8小时/4小时等）
- 每日定时更新资金费率周期信息，避免频繁API调用
- 对无法获取周期的交易对，使用默认周期并添加到自定义配置
- 自动管理自定义周期配置，移除已成功获取周期的交易对

### 3. 定时任务调度
- **测试模式**：每1分钟执行一次完整套利流程
- **生产模式**：每小时58分执行一次完整套利流程
- 每日00:01异步更新资金费率周期信息

### 4. 交易对筛选流程
- 调用币安API获取所有交易对的实时资金费率
- 筛选出资金费率在指定区间内的交易对
- 按资金费率绝对值排序，选择前N个高收益交易对
- 检查交易对是否在可交易列表中

### 5. 限价单处理
- 检查所有未成交的限价平仓单
- 对已成交的限价单进行平仓处理
- 对未成交的限价单，检查是否需要提前平仓
- 根据交易对是否在筛选结果中，决定保留或取消限价单

### 6. 套利交易执行
- **开仓时机**：资金费计费前3秒执行市价开仓
- **开仓规则**：
  - 资金费率为正 → 市价做空
  - 资金费率为负 → 市价做多
- **开仓资金**：总仓资金 × 单笔资金百分比
- **平仓时机**：资金费结算完成后延迟指定秒数
- **平仓规则**：资金计费150毫秒后执行限价保本平仓
- 持续监控限价单状态，计算平仓损益
- 未成交限价单，根据其下次资金费时间前的资金费率，判断是否需要提前平仓

### 7. 资金费率信息获取
- 一次性获取所有交易对的历史资金费率数据
- 对缺失历史数据的交易对，使用合理默认值处理
- 自动维护资金费率周期配置，确保数据准确性

### 8. 利润计算与统计
- 计算开平仓手续费（双向）
- 计算市价单滑点成本
- 计算实际资金费收益
- 累计总收益，自动滚仓
- 生成详细的利润明细

### 9. 异常处理与容错机制
- 单个交易对异常不影响全局运行
- 完善的API请求异常捕获
- 自动重试机制，提高系统稳定性
- 详细的错误日志记录

### 10. 通知与监控
- 开平仓操作实时记录
- 收益明细自动统计
- 支持钉钉机器人通知（可配置）
- 关键操作日志输出

## 📌 项目配置
### 核心配置项
| 配置项 | 说明 | 默认值 |
| --- | --- | --- |
| API_KEY | 币安API密钥 | - |
| API_SECRET | 币安API密钥密码 | - |
| DINGTALK_WEBHOOK | 钉钉机器人Webhook | - |
| DINGTALK_SECRET | 钉钉机器人密钥 | - |
| FUNDING_RATE_LOWER | 资金费率下限 | 0.0014 (±0.14%) |
| FUNDING_RATE_UPPER | 资金费率上限 | 0.02 (±2%) |
| ADVANCE_ORDER_SECONDS | 开仓提前秒数 | 3秒 |
| INITIAL_TOTAL_MARGIN_USDT | 初始总仓资金 | 100 USDT |
| SINGLE_TRADE_PERCENTAGE | 单笔资金百分比 | 0.2 (20%) |
| MAX_SYMBOLS | 最大交易对数量限制 | 2 |
| STOP_LOSS_RATE | 强制止损比例 | 0.05 (5%) |
| TEST_MODE | 测试模式开关 | True |
| DAILY_UPDATE_INTERVAL | 资金费周期数据更新间隔 | 24小时 |
| UPDATE_OFFSET_RANGE | 资金费周期更新偏移范围 | (30, 300)秒 |

## 📌 快速开始
### 1. 配置API密钥
编辑 `config.py` 文件，填入您的币安API密钥和密码：
```python
API_KEY = "您的API_KEY"
API_SECRET = "您的API_SECRET"
```

### 2. 配置钉钉机器人（可选）
如需接收通知，配置钉钉机器人：
```python
DINGTALK_WEBHOOK = "您的钉钉Webhook"
DINGTALK_SECRET = "您的钉钉密钥"
```

### 3. 调整套利参数（可选）
根据需要调整核心套利参数：
```python
FUNDING_RATE_LOWER = 0.0014  # 资金费率下限
FUNDING_RATE_UPPER = 0.02    # 资金费率上限
INITIAL_TOTAL_MARGIN_USDT = 100  # 初始总仓资金
SINGLE_TRADE_PERCENTAGE = 0.2  # 单笔资金百分比
```

### 4. 运行程序
```bash
# 直接运行
python main_new.py

# 后台运行（推荐）
nohup python -u main_new.py > arbitrage.log 2>&1 &
```
