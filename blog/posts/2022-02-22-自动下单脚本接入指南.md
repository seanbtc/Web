### 一.我能为你做什么？
1. 接收你的tradingview策略下单警报，连接你的账号自动下单（自动交易）
2. 使用我的策略，连接你的账号跟单（自动跟单）
3. 满足你的需求请往下看

### 二.使用条件
1. 不收取任何费用，但是接入的账号必须是我的推荐账号
2. 满足我的条件请往下看

### 三.接入流程 
*   自动跟单
    1. 注册账户
    2. 提供账号信息
        *   账户id
        *   账户api（只需勾选读取和合约交易权限）
![](/blog/assets/2022-02-22-%E8%87%AA%E5%8A%A8%E4%B8%8B%E5%8D%95%E8%84%9A%E6%9C%AC%E6%8E%A5%E5%85%A5%E6%8C%87%E5%8D%97/img1.jpg)
    3. 沟通策略选择，初始仓位等信息即可

*   自动交易
    1.注册账户
    2.提供账号信息
    3.修改你的警报
![](/blog/assets/2022-02-22-%E8%87%AA%E5%8A%A8%E4%B8%8B%E5%8D%95%E8%84%9A%E6%9C%AC%E6%8E%A5%E5%85%A5%E6%8C%87%E5%8D%97/img2.jpg)
    *   webhook url
```
http://43.154.192.***:80/order
```

    *   消息
```
{
	"side": "{{strategy.order.action}}",
	"quantity": "{{strategy.order.contracts}}",
	"price": "{{strategy.order.price}}",
	"ticker": "{{ticker}}",
	"ordertype": "limit",
	"exchange": "api key的前八位",
	"apisec": "secret key的前八位"
}
```

        解释：
```
side：下单方向(自动获取，不用动)
quantity：下单数量(自动获取，不用动)
price：下单价格(自动获取，不用动)
ticker：币种(自动获取，不用动)
ordertype：下单模式（市价单market 限价单选limit）
exchange和apisec可以理解为账号密码
```

 ### 4.交易所设置
     1. 设置单项持仓
     2. 全仓模式
     3. 杠杆倍数设置3倍以上
